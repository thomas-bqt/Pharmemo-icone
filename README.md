# Pharmémo – icône

Icône de l'application Pharmémo (Institut Maria Goretti) : Mémo, la gélule bleue et corail.

- `icone_192.png` : utilisée par l'application (onglet du navigateur, raccourci de l'écran d'accueil sur Android).
- `icone_1024.png` : grande version, lien « Icône Pharmémo » du support Classroom (les élèves sur iPhone l'enregistrent dans Photos).

Ce dépôt est **public** et ne contient que ces images : aucune donnée d'élève, aucun code.
Ne renommer ni déplacer aucune des deux images. L'application lit l'adresse
https://raw.githubusercontent.com/thomas-bqt/Pharmemo-icone/main/icone_192.png (Config.js, ADRESSE_ICONE).
Le support Classroom renvoie à https://raw.githubusercontent.com/thomas-bqt/Pharmemo-icone/main/icone_1024.png.
